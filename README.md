# Software Engineering Course Project

This repository is reserved for the software engineering course project.

## Repository Layout

- `src/` - application source code
- `tests/` - automated and manual test materials
- `docs/` - requirements, architecture, decisions, and project notes
- `scripts/` - repeatable development and project-management scripts
- `reports/` - course deliverables and generated reports
- `assets/` - approved images, diagrams, and other project assets

## Working Agreement

1. Record meaningful work in `docs/operation-log.md`.
2. Keep requirements, design decisions, implementation, and tests traceable.
3. Do not commit passwords, tokens, private keys, local environment files, or generated dependencies.
4. Use small, descriptive commits, for example:
   - `docs: define initial requirements`
   - `feat: implement user registration`
   - `test: cover login validation`
5. Push work to GitHub regularly after reviewing `git status`.
